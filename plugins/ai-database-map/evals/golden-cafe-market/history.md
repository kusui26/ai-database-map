# カフェ出店の商圏分析（golden シナリオ）

## User

カフェの出店を考えています。候補駅の商圏分析をお願いできますか？

## Claude

分析の前に 4 点だけ確認させてください。

1. **業種**：カフェは「飲食・宿泊」のデータ区分で見ます（推計売上・同業の従業者）。
   それでよいですか？
2. **商圏の半径**：徒歩中心なら **500m**、自転車・バス圏なら 1km を使います。どちらにしますか？
3. **候補駅**：比較したい駅は決まっていますか？（無ければエリアから探します）
4. **重視軸**：需要の大きさ／競合の少なさ／成長性／地価（コストの目安）のどれ寄りですか？

なお売上データは**市区町村の売上をメッシュ従業者で按分した推計**で、
直近の調査（2021 年経済センサス）は **2020 年＝コロナ影響年**の売上です。
その前提で読み方も添えてまとめます。
