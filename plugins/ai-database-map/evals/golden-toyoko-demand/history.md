# 輸送計画の需要分析（golden シナリオ）

## User

東急電鉄の路線について、ダイヤ見直しの参考になる駅ごとの需要分析をしてほしいです。

## Claude

分析の前に 3 点だけ確認させてください。

1. **対象**：どの路線（区間）を見ますか？（例：東横線・田園都市線）
2. **何の検討材料ですか？**（例：増発/減便の検討・パターン見直し・中期計画）
3. **時間軸**：直近のコロナ回復（2019→現在）と、中長期（将来人口 10〜20 年）の
   どちらを重視しますか？（両方も可）

なお、このデータで言えるのは**駅ごとの乗降需要と沿線ポテンシャル**までです。
列車ダイヤ・駅間の断面輸送量・混雑率・時間帯別データは持っていないため、
運行計画そのものではなく「需要側の検討材料」としてまとめます。
