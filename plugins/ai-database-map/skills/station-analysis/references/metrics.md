# 指標キーの規約（詳細）

## 命名

- カタログキーは `{接頭辞}_{年}_{半径}`。増減率は `{接頭辞}_{新しい年}_{古い年}_{半径}`
  （例 `pop_gr_2020_2015_1km` ＝ 1km 圏人口の 2015→2020 増減率）。
- **正確なキーは必ず `get_metrics_catalog` で確認する**。年次・半径の組み合わせは
  指標ごとに違う（無い組み合わせがある）。

## ファミリ名の例（既定：半径 1km・直近）

| ファミリ     | 意味                   |
| ------------ | ---------------------- |
| `pop_gr`     | 人口の増減率           |
| `lp_med`     | 地価の中央値           |
| `lp_gr`      | 地価の増減率           |
| `bus_n`      | バス停数               |
| `rate_covid` | 乗降客数のコロナ前後比 |

上記は例であり、全一覧・正確な単位・利用可能な年次はカタログを引くこと。

## 半径

500 / 1000 / 2000 / 5000 / 10000 / 20000 m の 6 段（事前計算値）。任意半径は不可。
半径非依存の指標（駅そのものの値：乗降客数など）では `radiusM` は無視される。

## 信頼性フラグ

- ランキングの `flagged: true`・散布の `excludeLowN` は「母数が小さい／極端値」の注意。
- 既定では表示に含めてよいが、**⚠ を付けて理由を書く**。統計的な結論に使うときは除外を検討し、
  除外したら件数を明示する。

## 0 件のとき

路線・会社の絞り込みで 0 件のときは、綴り（正式名称か）と「会社と路線の組み合わせ」を疑う。
応答の `note` / `hint` に従い、勝手に「データが無い」と結論しない。
