# 指標キーの規約（詳細）

## 命名

- カタログキーは `{接頭辞}_{年}_{半径}`。増減率は `{接頭辞}_{新しい年}_{古い年}_{半径}`
  （例 `pop_gr_2020_2015_1km` ＝ 1km 圏人口の 2015→2020 増減率）。
- **正確なキーは必ず `get_metrics_catalog` で確認する**。年次・半径の組み合わせは
  指標ごとに違う（無い組み合わせがある）。

## ファミリ名の例（既定：半径 1km・直近）

| ファミリ           | 意味                                                          |
| ------------------ | ------------------------------------------------------------- |
| `pop_gr`           | 人口の増減率                                                  |
| `pop_gr_pred`      | 将来人口の増減率（推計・年を省くと 2020→2050）                |
| `pop15_64`         | 生産年齢人口（15〜64 歳・2020 年）                            |
| `pop65_share`      | 高齢化率（65 歳以上の割合・2020 年）                          |
| `pop15_64_gr_pred` | 生産年齢人口の将来増減率（推計・2030／2040／2050・既定 2050） |
| `pop65_gr_pred`    | 65 歳以上人口の将来増減率（推計・2020→2050 だけ）             |
| `lp_med`           | 地価の中央値                                                  |
| `lp_gr`            | 地価の増減率                                                  |
| `bus_n`            | バス停数                                                      |
| `rate_covid`       | 乗降客数のコロナ前後比                                        |

上記は例であり、全一覧・正確な単位・利用可能な年次はカタログを引くこと。増減率の「直近」は 5 年だが、
将来推計の増減率だけは `get_area_summary` が先に言う 2050 年まで（2020→2025 年はもう過ぎた年）。

## 年齢

人口を年齢で分けた指標（カテゴリ population・将来は population_forecast）：2020 年の生産年齢人口（人数と割合）・
高齢化率・75 歳以上と年少人口の割合、生産年齢人口の増減率（2015→2020 年）、R6 推計の将来（15〜64 歳の増減は
2030・2040・2050 年、65 歳以上の増減と高齢化率は 2050 年）。全 6 半径。

- 日本語の名前（「高齢化率」「生産年齢人口」）でも解決され、読み替えが `note` に返る。あいまいな語（「高齢者」）や、
  ファミリ名のあとに年・半径でない語が続く指定（`pop_young` など）は、黙って総数の人口にならず、候補（`didYouMean`）が返る
- 年齢は住んでいる人の数で、乗降客数・通勤者数の予測ではない（需要の材料）
- 2015・2020 年の年齢不詳は、市区町村の不詳補完値に合わせて割り振ってある（4 区分の和＝総数の列）

## 半径

500 / 1000 / 2000 / 5000 / 10000 / 20000 m の 6 段（事前計算値）。任意半径は不可。
半径非依存の指標（駅そのものの値：乗降客数など）では `radiusM` は無視される。

`radiusM` は**各駅の周りを何 m で集計するか**で、探す範囲ではない。「竹橋から 5km 以内の駅」は
`near: {station: "竹橋", withinM: 5000}` で絞る（`rank_stations` / `compare_growth` / `list_stations` /
`build_dataset` で同じ）。返却の各駅に起点からの距離（`distance`）が付くので、距離は自分で計算しない。

## 信頼性フラグ

- ランキングの `flagged: true`・散布の `excludeLowN` は「母数が小さい／極端値」の注意。
- 既定では表示に含めてよいが、**⚠ を付けて理由を書く**。統計的な結論に使うときは除外を検討し、
  除外したら件数を明示する。
- 年齢の指標（2050 年の高齢化率 `pop65_share_pred` 以外）には、母数のフラグとは別に**年齢不詳の注意**
  `pop_ageunk_{年}_{半径}`（1＝補う前の年齢不詳が 10% 以上＝年齢の構成の多くを補った値）がある。
  ランキングの ⚠ には**出ない**——`build_dataset` の CSV に自動で付く列で見て、該当する駅の年齢の値には注記する。
  65 歳以上の将来増減率の母数のフラグは `pop65_lowbase_*`（65 歳以上が 50 人未満）。

## 0 件のとき

会社・路線・市区町村・起点の駅の名前はサーバが解決する（路線は利用者の呼ぶ路線＝運行系統。「山手線」は環状の 30 駅）。
決まらないとき（同じ名前の別路線・区「中区」・駅「府中」・データに無い名前）は図を作らずに `problems`（候補つき）を返すので、
それに従って呼び直すか利用者に確かめる。
0 件（`noFigure`）は名前ではなく**条件の組合せ**のせいなので、条件を緩めるか 0 件だったことを伝える。
応答の `note` / `hint` に従い、勝手に「データが無い」と結論しない。
