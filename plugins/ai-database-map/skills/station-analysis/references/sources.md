# 出典・ライセンスの扱い

- ツール応答に含まれる出典（`sources` や出典の文字列）を、**そのまま**回答の末尾に列挙する。
  言い換えたり省略したりしない（出典の表示は各データの利用条件）。
- 主な提供元：国土交通省（国土数値情報・ハザードマップポータルサイト）、総務省統計局（e-Stat 国勢調査）、
  気象庁（警報・注意報）、国土地理院（指定緊急避難場所・逆ジオコーディング・地図タイル）。
  **どのデータがどの出典かは応答が持っている**——自分で対応表を作らない。
- 数値は各公的統計の**二次加工**であり、原典の定義・年次・集計単位に依存する。
  商用利用の可否・条件は原典のライセンスに従う（一部に非商用条件のデータがある）。
  詳細はアプリの About（https://ai-database-map.vercel.app の ⓘ）を案内する。
