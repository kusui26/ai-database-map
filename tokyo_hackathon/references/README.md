# AI Database Map

個人開発した「Station Area Database Map」をAIネイティブなアプリに進化させることを目指しています。
※Station Area Database Map：駅周辺のオープンデータ（乗降客数、人口、地価等）を可視化した「データベース×マップ」のWebアプリ

## メンバー

- [臼井 健祐(usui kensuke)](../../people/profiles/kusui26.md) — オーナー / 個人参加

## プロジェクト

- **AI Database Map** — オープンデータの可視化アプリ
  - コンセプト: オープンデータを誰でも分かりやすく使えるようなWebアプリ
  - 活用想定: 鉄道会社の輸送計画、店舗出店の商圏分析、個人の住宅購入　等
  - BootCamp 期間の目標: 個人開発した「Station Area Database Map」をAIネイティブなアプリに進化させること
